\# Changelog



All notable changes to this project are documented in this file.



\## \[1.0.0] - 2026-11-03



\### Added

\- Initial AIMS DVD management application.

\- Display DVD list.

\- Add DVDs to shopping cart.

\- Search DVDs by title.

\- Calculate shopping cart total.

\- Apply quantity-based discounts:

&#x20; - 10% discount for 2 DVDs or more.

&#x20; - 15% discount for 3 DVDs or more.

\- Unit tests for DVD creation, initial DVD list, and adding DVDs to cart.

\- GitHub Actions workflow for automated Python unit testing.



\### Improved

\- Updated README documentation.

\- Added `.gitignore` to exclude temporary Python files.



\### Development

\- Practiced Git branching, merging, pull requests, merge conflict resolution, revert, release tags, hotfix, and cherry-pick.
