# \## 1. Introduction

# 

# AIMS (An Internet-based Advanced Management System)

is a DVD management application written in Python for managing DVD purchases.

# 

# \## 2. Features

# 

# \- Display DVD list

# \- Add DVD to shopping cart

# \- Display shopping cart

# \- Calculate total price
